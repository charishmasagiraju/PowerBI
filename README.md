# Data Professional Survey Analysis Dashboard

## Overview

This Power BI project analyzes survey responses from data professionals worldwide to uncover insights about salary trends, job satisfaction, work-life balance, programming language preferences, and the challenges of entering the data industry.

The dashboard was created using Power BI Desktop and focuses on transforming raw survey data into meaningful business insights through interactive visualizations.

## Dashboard Preview

![Dashboard Screenshot](dashboard.png)

## Dataset

The dataset contains responses from approximately 630 data professionals and includes information such as:

- Job Title
- Country
- Salary Range
- Industry
- Favorite Programming Language
- Age
- Work-Life Balance Satisfaction
- Salary Satisfaction
- Difficulty of Breaking into Data

## Dashboard Insights

### Salary by Job Title
- Data Scientists reported the highest average salaries.
- Data Engineers and Data Architects also earned relatively high salaries.
- Students and job seekers reported the lowest salary ranges.

### Programming Language Preferences
- Python emerged as the most preferred programming language.
- R was the second most popular language among respondents.
- JavaScript, Java, and C/C++ showed comparatively lower usage.

### Geographic Distribution
- Most survey respondents were from the United States.
- India, Canada, and the United Kingdom also contributed significantly.

### Job Satisfaction
- Average Work-Life Balance Rating: **5.74 / 10**
- Average Salary Satisfaction Rating: **4.27 / 10**

### Difficulty Entering the Data Field
- A large number of respondents reported that breaking into the data industry was either **Difficult** or **Very Difficult**.
